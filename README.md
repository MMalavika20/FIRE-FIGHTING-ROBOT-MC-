
#  Fire Fighting Robot

##  Project Overview

The Fire Fighting Robot is an automated robotic system designed to detect and extinguish fire with minimal human intervention. It uses flame sensors to identify the presence and direction of fire and an Arduino microcontroller to control the movement of the robot and activate the water pump.

The main aim of this project is to reduce human risk during fire emergencies by developing an automatic fire detection and extinguishing system.

##  Objectives

- To detect fire automatically using flame sensors.
- To identify the direction of the fire.
- To move the robot towards the fire source.
- To extinguish fire using a water pump.
- To demonstrate robotics and automation in fire safety.

##  Components Used

- Arduino UNO
- Flame Sensors
- Motor Driver (L298N)
- DC Motors
- Water Pump
- Robot Chassis
- Battery
- Connecting Wires

##  Working Principle

The flame sensors continuously monitor the surroundings for fire. When fire is detected, the sensors send signals to the Arduino. The Arduino processes these signals and controls the motors to move the robot towards the fire source. Once the robot reaches the fire, the water pump is activated to spray water and extinguish the fire.
